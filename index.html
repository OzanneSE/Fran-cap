O download automático pode falhar por restrição de conteúdo misto (HTTPS→HTTP) ou porque o firmware dos óculos não libera CORS. Abra o link abaixo manualmente no Chrome, já conectado ao Wi-Fi dos óculos — isso funciona mesmo sem nenhuma configuração extra:
Quer que o download automático funcione? Veja AVANÇADO → Corrigir conteúdo misto. Isso resolve o bloqueio de HTTPS, mas se os óculos não enviarem cabeçalhos CORS o fetch direto continuará falhando — a abertura manual acima sempre funciona como alternativa.

Testado em 27/07: o comando de bateria só volta um ACK genérico (sem número de %). O que parecia funcionar antes era um bug lendo o byte errado do pacote — corrigido. Até acharmos o comando certo, este medidor fica vazio; acompanhe o console em AVANÇADO pra ajudar a identificar o byte certo.
ESPAÇO INTERNO EXPERIMENTAL
STATUS Não consultado
O protocolo do YJ02 não tem um comando de espaço/armazenamento confirmado ainda. Testes mostraram que 02 01 07/08/09 provavelmente não são reconhecidos (ACK genérico); 02 01 05 se comporta diferente e é o candidato mais promissor. Este botão testa os candidatos e mostra a resposta crua no console (aba AVANÇADO) pra você ajudar a decifrar o formato.
LIMPAR CACHE / FORMATAR EXPERIMENTAL
Comando não confirmado oficialmente — pode não fazer nada, ou pode apagar arquivos dos óculos. No teste de 27/07 o comando "02 01 04 03" pareceu reativar a transmissão das credenciais de Wi-Fi (não deu pra confirmar se limpou algo). Só use se souber o que está fazendo e, de preferência, com os arquivos já importados.
